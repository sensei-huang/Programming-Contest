# How to view PDF files more efficiently

To view the PDF files in browser instead of inside Github, perform the following steps:
1. Copy Github link of the PDF.
2. Go to this [link](https://regex101.com/r/ulQS7Z/1) and paste your Github link. Alternatively use matching regex ```https:\/\/github\.com\/(sensei-huang\/Programming-Contest\/)blob\/main(\/NZPC\/2016\.pdf)``` and replace it with ```https://docs.google.com/viewer?url=https://raw.githubusercontent.com/$1master$2```
