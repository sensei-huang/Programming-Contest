# Format

Regionals problems are in the regional folder and divisional problems are in the division folder. If you are practicing, you should probably practice divisonal problem sets A unless you are practicing for regionals(meaning you have qualified from divisional competition) or want harder problems. A few exceptions in years are explained below:
| File suffix | Meaning |
| ----------- | ------- |
| A/B | A is the higher level division and the one you need to go to regionals while B is for beginners. |
| R1/R2 | This was due to COVID-19 and so there was only 1 competition and 2 divisions |
| W/C/E | West, central and eastern divisions |
