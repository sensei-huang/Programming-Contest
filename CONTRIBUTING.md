# Contributing
If you would like to contribute a solution, please email me using my [email address](mailto:samuelminghuang@gmail.com).  

Please attach the solution as a file and in the subject name, include the problem letter, the year and any additional things to help identify the problem(e.g. division, regionals, etc.).  

It would be helpful to the viewer if you commented code and followed code conventions(e.g. intuitive naming, modular code, correct spacing, etc.); however this is not required.

If your approach is different to the current solution, feel free to still contribute. Multiple approaches help foster creativity and flexibility.
